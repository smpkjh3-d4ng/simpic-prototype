# Simpic 프로토타입

함께 찍은 사진을 한 앨범에 모으는 앱 **Simpic**의 인터랙티브 프로토타입입니다.

- `index.html` — 초기 사용자 흐름 프로토타입 (DESIGN.md 적용). 온보딩부터 시작하고 앨범이 비어 있어요.
- `existing-user.html` — 기존 사용자 프로토타입. 온보딩 없이 홈에서 시작하고 앨범(콜라보 카페, 상업공간 답사, 도쿄 우정여행, 속초 여행)·그룹·친구가 들어 있어요.

## 디자인 문서

- `AGENTS.md` — 코딩 에이전트(Codex·Claude Code)가 가장 먼저 읽는 작업 안내. 읽을 순서·작업 규칙·확인 방법
- `DESIGN.md` — 색·글자·간격·모서리·그림자 토큰과 컴포넌트·화면 규칙 (9주차, 구글 design.md 형식)
- `VOICE.md` — 보이스앤톤, 문장 규칙, 용어집, 상황별 톤 (10주차 UX 라이팅)
- `accessibility-guide.md` — WCAG 2.2 AA 기준과 Simpic 접근성 규칙
- `component.md` — Figma 컴포넌트 목록·variant·속성과 사용법 (Figma `Components(수정용)` 기준)
- `contract.md` — 토큰·컴포넌트·동작 계약, 토큰 변경 절차, 확인 방법 (초안)
